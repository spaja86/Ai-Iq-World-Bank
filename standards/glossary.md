# Repository Glossary

| Term | Meaning |
|---|---|
| AI IQ World Bank | The repository and concept space combining prototype, standards, planning, and governance assets |
| INDEKURILANC | The active repository readiness-scoring model for AI capability maturity |
| DINAR | Controlled internal/scenario unit governed by `dinar-standard-plan.md` |
| Standard | A normative document that defines a canonical rule or controlled concept |
| Governance | Repository rules for review, approval, publication, risk, or handling |
| Template | A fill-in document intended for repeated structured use |
| Working document | A document that is usable but not yet locked as final canonical guidance |
| Approved document | A document treated as stable repository guidance |
| Sanitized output | A version prepared for sharing with sensitive details removed or aggregated |
| Public output | A version suitable for wider distribution under legal/reputational controls |
| Internal output | A version intended for restricted operational use |
| Repository-relative reference | A sibling filename or repository path used instead of an environment-specific absolute filesystem path |
